# 🧑‍💻 How to Run the Projects

## 1. Clone the repository

```bash
git clone https://github.com/vankayalavamsi-arch/HTML-CSS-JS-Projects.git
```

## 2. Open the project folder

```bash
cd HTML-CSS-JS-Projects
```

## 3. Run a project

Open the required project's `index.html` file in your browser.

For development, you can also use **VS Code + Live Server**.
